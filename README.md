# Démo – Portail municipal de Gbéléban

Cette version de démonstration fonctionne avec **Django + SQLite + GeoJSON + Leaflet + Chart.js** et est prévue pour un déploiement simple sur **Render**.

Le projet contient le site institutionnel, une interface d’administration, les actualités et projets, un WebSIG public, un espace Urbanisme protégé, un mini-module fiscalité et un dashboard de démonstration.

> Les données fiscales et certains objets cartographiques inclus sont fictifs et servent uniquement à la démonstration.
